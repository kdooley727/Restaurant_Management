# Restaurant_Management
I built Restaurant_Management as a comprehensive desktop application for managing core operations within a restaurant. Using C# and the .NET Framework, I implemented features that support menu management, order processing, reservations, user authentication, and feedback collection. The application uses a Windows Forms GUI for intuitive interaction, and leverages MongoDB for persistent data storage (as shown by MongoDbHelper.cs and the presence of MongoDB-related libraries).

Key Features:

Menu management, including editing and tracking menu items (Menu.cs, menumanagement.cs)
Order placement, tracking, and management (Orders.cs, order.cs, ordering.cs, ordertracking.cs)
Reservation system to handle table bookings (Reservations.cs, reservation.cs)
User registration and login functionality (User.cs, registration.cs, login.cs)
Customer feedback collection and management (Feedbacks.cs, feedback.cs)
Resource and settings management for localization and configuration (Resources.Designer.cs, Settings.Designer.cs)
Integration with MongoDB for data persistence
